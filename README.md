Triangle Checker
A simple Python program that checks whether three given segments can form a triangle.

About
This project was created to practice conditional statements, logical operators, and mathematical conditions.

How It Works
The program asks the user to enter the lengths of three segments.

For three segments to form a triangle, the sum of any two sides must be greater than the third side.

The program checks:

a + b > c
a + c > b
b + c > a

If all three conditions are true, the segments can form a triangle.

Technologies
Python

How to Run
Clone the repository:

git clone https://github.com/YOUR-USERNAME/triangle-checker.git

Enter the project folder:

cd triangle-checker

Run the program:

python main.py

Example
Enter the first segment: 5
Enter the second segment: 4
Enter the third segment: 3

These segments can form a triangle.
